# Fastidious Client releases

Installers for the Fastidious Client, the desktop companion for Watcher of Realms from
[fastidious.gg](https://fastidious.gg). It reads your account from the running game on your own PC and shows it
locally. Nothing leaves your computer unless you link it with fastidious.gg.

Download the latest Windows installer from [Releases](../../releases/latest). Once installed, the app updates
itself from here.

This repository holds only the release files (installers, their update signatures and `latest.json`). The
source code is not published.
